# Manufacturing OEE Dashboard - SQL + Power BI

## Project Overview
Tracking Overall Equipment Effectiveness (OEE) for manufacturing line to reduce downtime and improve productivity.

## Business Problem
- Machine downtime was high (15-20%)
- No visibility on why machines stop
- Quality rejection was not tracked shift-wise

## Tools Used
- SQL (MySQL) - Data Cleaning & Analysis
- Power BI - Dashboard & Visualization
- Excel - Raw Data

## KPIs Tracked
- Availability = (Operating Time / Planned Production Time)
- Performance = (Actual Output / Ideal Output)
- Quality = (Good Pieces / Total Pieces)
- OEE = Availability * Performance * Quality

## Key Insights (Sample)
- Top downtime reason: Material Shortage (35%)
- Lowest OEE Shift: Night Shift (62%)
- Machine M3 has highest breakdowns
